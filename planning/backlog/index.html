    Доска контрактов, лицензии, страховка, гонки¶

    • Курьерские: запечатанный ящик на waystone X в диких землях; оплата + залог; груз можно отбить → профессии пирата и эскорта.
    • Охотничьи: баунти на мобов/боссов/игроков (на игроков — только в диких землях).
    • Ресурсные: заказ на партию материалов (как buy-ордера в EVE).
    • Ранги лицензий на доске: Кадет → Пилот → Ас → Капитан; экзамены усложняются (кольца → полоса на время → шторм → бой с дроном). Обрывок про привилегии: «скидку на док, право брать курьерские контракты высокого уровня». В паке сейчас другая шкала предметов — лицензии пилота.
    • Страховка корабля: взнос → часть стоимости при потере (сток валюты, цитата EVE).
    • Гонки еженедельно, трасса меняется, таблица рекордов.
    • Рядом подписи «NPC», «активные кольца для экзаменя», «Bountiful» (на доске без расшифровки).
    • Отдельная заметка: «Проверить механику разрушения корабля».
    • «Рыбаки отдельный вид игроков, которые снабжают уникальной рыбок всех игроков».

    Семь идей своих модов/скриптов¶

    На доске: готовых аналогов нет, MVP большинства — KubeJS + датапаки, полноценные моды — на второй сезон.

    1. Небесные пираты — NPC-дирижабли / статичные платформы с лутом как MVP.
    2. Система штормов — урон кораблям, молнии, редкий лут («штормовые кристаллы»).
    3. Радар/транспондер — метки кораблей; выключенный транспондер = невидим, но нельзя докаться в городе.
    4. Захват waystone — лёгкий мод поверх Waystones API, окна уязвимости, лог захватов.
    5. Груз-контейнеры — запечатанный блок, дропается с корабля.
    6. Небесные левиафаны — редкие «киты», гарпун, командный PvE.
    7. Чёрный ящик — координаты/время гибели корабля (без ников в Незере).

    Контентные моды «проверить под 1.21.1 NeoForge»¶

    Список-рекомендация, не бэклог сборки. Часть уже в паке (Create-экосистема, Waystones, Simple Voice Chat, Xaero's, EMI/Jade, spark и т.д. — см. список модов). Из того, чего в текущем индексе нет как явного направления: Steam 'n' Rails, Iron's Spells / Ars Nouveau, Better Combat, FTB Chunks/Teams как замена OPAC, Lightman's Currency (в паке — Numismatics + Marketplace), Distant Horizons.

    Техтребования (заметка на доске)¶

    Тот же консультантский блок: упор на одно ядро CPU из‑за Create + физика; 16–24 ГБ RAM; Velocity + отдельные инстансы Спавн/Строители / Дикие земли / Незер; преген Chunky; цель онлайна 30–60, «не обещайте 200»; лимиты размера корабля и контрапшенов; обновления сначала на стейдже. Это не принятый хостинг-план, пока нет задачи в канбане.

    «2 сезон — Create + Apotheosis» и «Create: Apokinetics» — на роадмапе.
