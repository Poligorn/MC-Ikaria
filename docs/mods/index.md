# Моды

Актуальный перечень снят с Packwiz-метаданных `mods/*.pw.toml` пака **0.6.2** (147 записей). Старые страницы, где фигурировали Botania, Mekanism, AE2, Terralith, Macaw's, JEI, Lithium, Fabric API и Valkyrien Skies 2, **не соответствуют** текущей сборке.

- [Полный список по категориям](mod-list.md)
- [Экосистема Aeronautics](aeronautics.md)

Источники ссылок: поле `[update.modrinth] mod-id` → страница Modrinth; `[update.curseforge] project-id` → CurseForge. Описания возможностей сверены с карточками модов; роль в паке — с KubeJS и конфигами. Если проверить поведение было нельзя, формулировка общая.
