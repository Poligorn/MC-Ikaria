# Летающие острова

Мир пака — небо, а не сплошная земля. Есть два слоя: **общий хаб**, который ставит KubeJS, и **процедурные острова** Aero Islands.

## Общий стартовый остров (ASI)

KubeJS (`kubejs/server_scripts/Spawn/`, структура `kubejs/data/asi/structure/starter_island.nbt`):

| Параметр | Значение |
|----------|----------|
| Измерение | `minecraft:overworld` |
| Угол структуры | (-8, 200, -8) |
| Смещение игрока | +12 / +5 / +12 |
| Флаги | `asi_island_placed` (сервер), `asi_started` (игрок) |

Остров ставится при загрузке мира (с повторами) и ещё раз экстренно, если игрок зашёл раньше, чем структура успела появиться. Без этого новичок падает в пустоту.

Наследие: `kubejs/data/asi/function/on_join.mcfunction` выставляет spawn на `5 205 5` — координаты близки к хабу.

## Процедурные острова

Мод **Aero Islands** (Aeroscapes, Modrinth `tGVwBATM`) — генерация летающих островов под Create Aeronautics. В ресурспаке **ASI RU** есть строки биомов вроде void shores / voidsea / hallowed isles — это локализация генератора, не отдельный мод.

**Create: Sky Village** и **Sky Villages** добавляют деревни в небе. **Sky Whale Ship** — структуры «китов» в небе.

## Пустота

- **Forgiving Void** — падение вниз возвращает сверху (важно для островного мира).
- **Clear Void** — убирает чёрную «нижнюю» половину скайбокса.
- **Smooth Skies** — сглаживает небо; в конфиге включено затемнение войда на дистанции.

## Исследование

**Create Aeronautics Discovery** добавляет пролёты (flyovers), торговца Soaring Trader с картами структур и события столкновений суб-уровней.

**Traveler's Titles** показывает названия биомов при входе.

Подробнее о связанных модах: [Aeronautics](../mods/aeronautics.md), [список модов](../mods/mod-list.md).
