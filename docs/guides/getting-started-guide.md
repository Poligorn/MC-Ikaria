# Первые шаги

Краткий маршрут новичка по **фактическому** содержимому пака.

## 1. Не упасть

Вы на острове около Y 200. Без корабля или планера пропасть смертельна, но **Forgiving Void** вернёт сверху. Не стройте базу, свесившись с края, пока нет ограждения.

## 2. Журналы

- FTB **Aeronautics Journal**, глава «Первые исследования»: найти дневники (галочка), починить аэростат (8 оболочек + горелка из бочонков корзины), собрать параглайдер.
- Modopedia: три **дневника основателей** (Механик / Небоход / Следопыт) нужно найти в сундуках; на спавне их не дают. Первая запись открыта; остальные главы — за вырванными листами. Подробности: [дневники](modopedia.md).

## 3. Личный полёт

1. Добудьте **аэролит** (`aeroscapes:aerolite_twig`) на стартовом острове (92 блока руды; падает прутик).
2. Скрафтите **параглайдер** (4 палки + 3 аэролита; ванильный рецепт с кожей снят). Дерево на острове есть.
3. Позже: золотой аэролит → **clockwork-крылья** (нужны элитры и детали Create/Simulated).

Стамна планера настраивается в конфигах Paragliders.

## 4. Create и первый корабль

Прогресс Create как в ванильном моде: верстак → Andesite Alloy → кинетика. Для корабля нужны блоки Create Aeronautics (пропеллеры / горелка горячего воздуха / пар) и понимание, что корабль — контрапшен, который уходит в суб-уровень **Sable**.

Камера: Aeronautics Camera Sync. Не ставьте Waystones на корабль без аддона **Waystones: Sable**; крафт обычных waystones отключён.

## 5. Еда и ферма

**Farmer's Delight** + **Slice & Dice** (автоматизация Create) + **Botany Pots**. Рыбалка — **Starcatcher**. Это не индустриальный техпак: Mekanism / IE в сборке нет.

## 6. Опасности

- Рейды **Hostile Skies** могут прилететь по таймеру (см. [корабли](../mechanics/airships.md)).
- Дальше 1500 блоков от центра мира мобы с **Create: Gunsmithing**.
- Червоточины **не** безопасный Незер-хаб: у портала есть класс, таймер и лимит проходов. Берите радар. Подробности: [EVE](../lore/eve-online.md).
