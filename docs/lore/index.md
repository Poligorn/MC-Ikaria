# Лор

В паке два слоя повествования.

1. **Журнал игрока** (FTB Quests, книга *Мой журнал*) — записи персонажа; три имени (Элиас, Кайра, Рован) остаются тоном, не квестами на предметы. Тексты — `lang/ru_ru.snbt` и `lang/en_us.snbt`.
2. **EVE-inspired слой** — не канон New Eden, а механики и метафоры: червоточины, разведка, ранги пилота, «онлайн»-сервер. Подробности: [Отсылки к EVE Online](eve-online.md).

Внутриигровые дневники Modopedia (Механик / Небоход / Следопыт) **отложены** — JSON на месте, в мир не выдаются. [Гайд и как включить](../guides/modopedia.md).
