# Установка модпака

Сборка **MC ASI Online** 0.6.2: **Minecraft 1.21.1**, **NeoForge 21.1.250**, менеджер модов **Packwiz**.

!!! warning "Устаревшие инструкции"
    Старые страницы документации описывали Fabric 1.20.1. Это **не** текущий пак. Нужен именно NeoForge 1.21.1.

---

## Системные требования

### Минимум

| Компонент | Требование |
|-----------|------------|
| **Minecraft** | 1.21.1 |
| **Загрузчик** | NeoForge 21.1.250 |
| **Java** | 21 |
| **ОЗУ для игры** | 6 GB |

### Рекомендуется

| Компонент | Требование |
|-----------|------------|
| **ОЗУ для игры** | 8 GB |
| **Видеокарта** | дискретная (Sodium уже в паке; шейдеры Iris — опционально) |

!!! warning "Память"
    В лаунчере выделите не меньше **6144 MB**. Create Aeronautics и суб-уровни Sable требовательны к RAM.

---

## Способ 1: Prism Launcher (рекомендуется)

Packwiz-репозиторий удобно ставить через Prism:

1. Установите [Prism Launcher](https://prismlauncher.org/).
2. **Add Instance → Import** (или «Packwiz / URL», если доступно в вашей версии).
3. Укажите этот GitHub-репозиторий / ветку с `pack.toml`.
4. Дождитесь загрузки модов по `index.toml`.
5. В настройках инстанса: Java 21, `-Xmx6G` или больше.

Альтернатива: склонировать репозиторий и выполнить `packwiz serve` / `packwiz curseforge/modrinth` export, если пользуетесь экспортом.

---

## Способ 2: Ручная установка через Packwiz

1. Установите [packwiz](https://packwiz.infra.link/).
2. Клонируйте репозиторий:

    ```bash
    git clone https://github.com/Poligorn/MC-ASI-Online.git
    cd MC-ASI-Online
    ```

3. Поставьте моды в инстанс NeoForge 1.21.1. Сами `.jar` в git **не** хранятся: их качает Packwiz по `mods/*.pw.toml`.
4. Скопируйте в инстанс также `config/`, `kubejs/`, `resourcepacks/` — они входят в индекс пака.

!!! tip "Обновление индекса"
    После добавления файлов в репозиторий владелец/CI должны выполнить `packwiz refresh`, иначе новые датапаки не попадут в установку.

---

## Что не сработает

- Профиль **Fabric / Quilt / Forge** (нужен **NeoForge**).
- Версия Minecraft **не 1.21.1**.
- Установка «только модов» без `kubejs/` — пропадут стартовый остров, лицензии пилота и книги Modopedia.

---

## Настройка после установки

- **Memory:** минимум 6 GB, лучше 8 GB.
- **Render Distance:** 8–12 чанков на старте.
- **Шейдеры Iris:** выключены, пока не проверите FPS. В паке есть Sodium и Iris.
- Ресурспаки в `resourcepacks/` (в т.ч. **ASI RU**) включите, если нужна русская локализация аддонов.

---

## Решение проблем

!!! danger "Крэш при запуске"
    Проверьте Java 21, версию NeoForge и объём RAM. Смотрите `crash-reports/` и `latest.log`.

!!! warning "Низкий FPS"
    Снизьте дистанцию прорисовки, отключите шейдеры, закройте лишние программы. Профилировщик **spark** уже в паке.

!!! bug "Моды не подхватились"
    Убедитесь, что инстанс собрался из Packwiz, а не из старого zip Fabric-пака.

---

## Проверка установки

- [ ] В списке модов есть **Create Aeronautics**, **Create**, **Sable**, **Eve Wormhole Portals**, **Modopedia**
- [ ] Нет Fabric API как загрузчика (это NeoForge-пак)
- [ ] При создании мира появляется стартовый остров, а не обычный оверворлд «с нуля на земле»
