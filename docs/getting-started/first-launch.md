# Первый запуск

При первом входе в мир KubeJS размещает общий стартовый остров и переносит игрока туда.

## Стартовый остров

Скрипты в `kubejs/server_scripts/Spawn/`:

- Структура `asi:starter_island` ставится в оверворлде от угла **(-8, 200, -8)**.
- Точка спавна игрока — со смещением **[+12, +5, +12]** от угла (центр площадки).
- Мировой спавн фиксируется, `spawnRadius` = 0.
- Флаг сервера `asi_island_placed` ставится **только если** под точкой спавна уже есть блок (не воздух).
- Флаг игрока `asi_started` — только после успешного телепорта на землю; иначе вход повторит попытку.

Сообщение при входе: «Добро пожаловать на Небесный Остров…» Книга квестов FTB и **три дневника основателей** (Modopedia) выдаются через `player.give()` — не командой `/item replace` (см. [дневники](../guides/modopedia.md)).

Остров ставится в `ServerEvents.loaded` **сразу** (без паузы 5 с). На первом входе телепорт повторяется каждые 10 тиков, пока не появится земля, максимум ~20 с.

Отладочные команды: `/asi resetisland`, `/asi placenow`, `/asi resetplayer`, `/asi status` (флаг + есть ли блок под спавном).

### Как проверить на новом мире

1. Удалите мир (или создайте новый).
2. Зайдите один раз: должны оказаться на площадке около **4.5, 205, 4.5**, не в пустоте.
3. В логе сервера: `[ASI] Остров на месте` и `[ASI] Игрок … на острове`.
4. `/asi status` — флаг `true`, земля `true`.
5. Если земля `false`: `/asi placenow`, затем `/asi resetplayer` и перезайдите.

## Что взять с собой с острова

1. Откройте **Aeronautics Journal** (FTB Quests) — текст про трёх Основателей.
2. Откройте три **дневника основателей** (Modopedia). Предисловие доступно сразу; остальные главы — за листами из сундуков.
3. Не прыгайте в пустоту без плана: сработает [Forgiving Void](../mods/mod-list.md), но падение всё равно опасно.
4. Для личного полёта нужен **параглайдер** (рецепт переведён на аэролит Aero Islands) — см. [первые шаги](../guides/getting-started-guide.md).

## Мир вокруг

- Генерация островов: **Aero Islands** (Aeroscapes) для Create Aeronautics.
- Пустое небо: **Clear Void**, **Smooth Skies**.
- Чужие корабли вдали: события **Create Aeronautics Discovery** и рейды **Hostile Skies**.
- Нестабильные порталы: **Eve Wormhole Portals** — [отсылки к EVE](../lore/eve-online.md).

## Лицензии пилота

Предметы `kubejs:pilot_license_*` (кадет → второй офицер → первый офицер → капитан → админ) регистрируются в KubeJS и надеваются в слот Curios `license`. В репозитории **нет** рецептов и квестов, которые выдают эти предметы: выдачу должен настроить сервер. Подробнее: [лор](../lore/eve-online.md).
