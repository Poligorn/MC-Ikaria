    Список модов¶

    Источник: Packwiz-файлы mods/*.pw.toml репозитория MC ASI Online 0.6.2 (Minecraft 1.21.1, NeoForge). В индексе 147 модов. Ссылки ведут на Modrinth или CurseForge по ID из .pw.toml.

    Что убрано из старой документации

    В паке нет Immersive Engineering, Mekanism, Applied Energistics 2, Botania, Ars Nouveau, Terralith, Chipped, линейки Macaw's, JEI, Lithium, Starlight, FerriteCore, Physics Mod, Inventory Profiles Next, Fabric API и Valkyrien Skies 2. Просмотр рецептов — EMI.
